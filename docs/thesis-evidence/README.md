# HERMES szakdolgozati háttércsomag

A csomag a HERMES többcéges flottakezelő megvalósítását dokumentálja. A vizsgált kiindulópont a `main` ág **`9421b69278601c8b7e73d032f88858dbc0bb4f2e`** commitja, 2026. november 25. A munkafa az elemzés előtt tiszta volt. A csomag összeállítása az alkalmazás forrását és üzleti működését érintetlenül hagyta. [Rögzített forrásállapot](https://github.com/NemodaMark/Hermes_flotter/tree/9421b69278601c8b7e73d032f88858dbc0bb4f2e)

| Anyag | Használat |
| --- | --- |
| [Műszaki háttéranyag](muszaki-hatter.md) | Technológia, architektúra, adatmodell, jogosultság, folyamatok, funkcióállapot és telepítés. |
| [Ábrajegyzék](abrajegyzek.md) | A négy tervábra, a tizenkét alkalmazáskép és a nyolc kódábra javasolt címe és fejezete. |
| [Tesztjegyzőkönyv](tesztjegyzokonyv.md) | Tényleges futtatások, ellenőrzési lépések, eredmények és korlátok. |
| [Fejlesztési döntések](fejlesztesi-dontesek.md) | Ellenőrizhető Git-előzmények és a belőlük levont következtetések. |
| [Hiánylista](hianylista.md) | Nyitott forráskérdések, személyes közreműködés és további próbák. |
| [Eszközök és reprodukció](tools/README.md) | Fiktív környezet, képkészítő és ábrageneráló parancsok. |

A funkcióállapot a forráskód és a kapcsolódó dokumentumok alapján készült. A futás közben ellenőrzött viselkedéshez a tesztjegyzőkönyv azonosítói és a képfájlok adják a bizonyítékot. A képek elkülönített, Development környezetben készültek a fiktív Demo Flottával. Az éles használat körülményeire és a fejlesztés személyes munkamegosztására a [hiánylista](hianylista.md) tartalmaz kérdéseket.
